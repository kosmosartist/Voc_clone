# Пайплайн для клонирования голоса для пения

Ниже — практичный пайплайн, ориентированный именно на **пение** (а не разговорную речь). Он использует комбинацию: **извлечение вокала**, **нейронная вокальная конверсия (SVC/VC)**, **синтез мелодии** и **финальный мастеринговый этап**.

> ⚠️ Важно: используйте **только легальные записи** и **письменное разрешение** владельцев голоса. Клонирование голоса без согласия — незаконно и неэтично.

---

## 1) Подготовка данных (датасет)

**Цель:** получить чистые, стабильные вокальные записи.

1. Соберите 15–60 минут вокала **без эффектов** (реверб/дилей/хорусы). Чем больше — тем стабильнее тембр.
2. Частота дискретизации: **44.1 kHz или 48 kHz**.
3. Разделите длинные треки на фрагменты по 5–20 секунд.
4. Удалите шумы, перегрузы, слишком тихие участки.

**Рекомендованные источники/инструменты:**
- Исходные STEM-ы (лучше всего) или single-треки с минимальными эффектами.
- Конвертация и нарезка: `ffmpeg`.

---

## 2) Извлечение вокала из микса (если нет STEM)

**Цель:** получить максимально чистый вокал.

Инструменты:
- `UVR` (Ultimate Vocal Remover) — GUI/CLI.
- `Demucs` — современный open-source инструмент разделения.

**Пример (Demucs):**
```bash
# 설치/запуск зависит от окружения
python -m demucs --two-stems=vocals input_song.wav
```

Результат: дорожка `vocals.wav`, которая будет основой для обучения.

---

## 3) Препроцессинг датасета

**Цель:** привести все файлы к единым требованиям модели.

1. Привести формат к `wav`.
2. Нормализовать громкость до -14 LUFS или -20 LUFS (зависит от модели).
3. Удалить тишину в начале/конце.
4. Опционально: выровнять питч (если у исходника сильно плавает строй).

**Пример обработки (ffmpeg):**
```bash
ffmpeg -i input.wav -ar 44100 -ac 1 -af "loudnorm=I=-16:TP=-1.5:LRA=11" output.wav
```

---

## 4) Обучение модели вокальной конверсии (VC/SVC)

**Цель:** научить модель преобразовывать любой входной вокал в целевой тембр.

Рекомендуемые open-source решения:
- **RVC (Retrieval-based Voice Conversion)** — де-факто стандарт.
- **so-vits-svc** — качественная певческая конверсия.

**Общий шаговый процесс:**
1. Извлечение фичей (Hubert/ContentVec).
2. Обучение модели на фичах и исходном вокале.
3. Валидирование качества конверсии.

**Ориентиры по обучению:**
- 10–20 минут вокала → базовое качество.
- 45–60 минут → стабильный тембр и артикуляция.

---

## 5) Генерация мелодии и текста (если нужен синтез)

**Варианты:**
- **Synthesizer + Pitch control:** генерируете «суррогат» вокал, затем конвертируете в целевой тембр.
- **MIDI + вокальный синтез:** готовите мелодию, затем преобразуете через VC.

Инструменты:
- `DiffSinger` — синтез пения по MIDI/lyrics.
- `VITS`-based singing models (если есть готовые модели).

---

## 6) Конверсия вокала (инференс)

**Цель:** заменить тембр исходного вокала на целевой.

Процесс:
1. Вход: «водящий» вокал (guide vocal).
2. VC-модель конвертирует тембр.
3. Доп. коррекция: эквалайзер, де-эссер, компрессия.

---

## 7) Финальный микс

**Цель:** интегрировать вокал в трек.

1. EQ (срез 80–120 Гц для вокала).
2. De-esser (5–8 кГц зона).
3. Компрессия (2:1–4:1).
4. Реверб/дилей (умеренно, чтобы не скрывать артикуляцию).
5. Лимитер на мастер.

---

## Пример минимального пайплайна (кратко)

1. Сырой вокал → очистка → `wav`.
2. Обучение RVC/so-vits-svc.
3. Guide vocal (или синтез) → VC-конверсия.
4. Финальный микс.
